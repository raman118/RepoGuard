# Security verification and remaining deployment limits

`uv run pytest tests/security` exercises archive names/bombs/devices, bounded bodies and secret-safe validation responses/logs, malformed signed events, injected repository instructions/dependencies/source, even rehashed unsafe patches, provider path/tool policy, authenticated validator replay and arbitrary command denial, and subprocess output bounds. Existing API suites cover cross-tenant reads/writes, delivery replay, approval digests, lease exhaustion/cancellation and retry-safe PRs. Real Docker network/host/PID/resource tests are separately marked sandbox; absent services are explicit skips, never safety evidence.

No repository code/dependency install/test executes on the host. Scanner reads data with safe parsers and fixed Semgrep config; worker launches trusted analysis code with deadline. Test execution occurs only in the restricted prebuilt validator image. Optional model receives rule/path metadata only, cannot call tools or produce executable free-form patches. Signed validator results and fresh nonces bind source/digest; approval is human authenticated. PR identity/base/head/URL are checked, with closure of a newly created invalid PR, and no force update/merge/deploy path.

REST bodies are bounded by actual bytes and total read deadline, webhooks have a distinct bounded allowance. Pydantic errors are sanitized to avoid reflecting secret-bearing input. GitHub responses are streamed/capped with fixed host, denied redirects and bounded deadlines; 401 clears cached credentials. Logs only record route templates and safe correlation/job fields. Disable Uvicorn raw access logs in deployment and use RepoGuard structured events.

Public SaaS deployment remains out of scope until OIDC/RBAC, per-tenant/global concurrency/rate quotas, automated retention/deletion, externally tested PostgreSQL locking, backup recovery, dedicated parser/validator host isolation and live installation ownership lifecycle have been reviewed. Operator bearer tokens provide tenant identity, not a public SaaS user/role system. API operations are bounded individually; aggregate authorized traffic still requires ingress limits. Shared-kernel containers retain escape risk; use disposable dedicated hosts/VMs and never mount Docker into API/scan workers. Validator service is internal-only with separate derived access credential, HMAC, two slots and replay window; do not give it platform secrets.

Static controls intentionally have limited coverage; see RULES.md and SCORING.md. Tagged image checks do not prove image immutability or CVE safety; test-command heuristics do not prove tests passed. Semgrep CLI and live sandbox execution are unverified in this Windows environment. Frontend dependency audit removed an unpatched glob dependency; full tree audit is a dated dependency result, not comprehensive security proof.
